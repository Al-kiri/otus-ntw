# Команды IOS. Базовая конфигурация устройств
## Часть 1. Проверка конфигурации коммутатора по умолчанию
*Почему нужно использовать консольное подключение для первоначальной настройки коммутатора? Почему нельзя подключиться к коммутатору через Telnet или SSH?*

Для подключения по SSH или Telnet требуется базовые настройки оборудования (ip, настройки доступа и тд) 
### Установите консольное подключение к коммутатору с компьютера PC-A с помощью Tera Term или другой программы эмуляции терминала.
>Press RETURN to get started!
>
>Switch>
### Проверьте настройки коммутатора по умолчанию.
>Switch>enable
>
>Switch#sho
>
>Switch#show run
>
>Switch#show running-config 
###	Изучите текущий файл running configuration.
*Сколько интерфейсов FastEthernet имеется на коммутаторе 2960?*

24 порта FastEthernet.

*Сколько интерфейсов Gigabit Ethernet имеется на коммутаторе 2960?*

2 порта GigibitEthernet.

*Каков диапазон значений, отображаемых в vty-линиях?*

16.
>Switch(config)#line ?
>

появляется, т.к. мы не изменяли и не сохраняли текущую конфигурацию
### Изучите характеристики SVI для VLAN 1.

*Назначен ли IP-адрес сети VLAN 1?

### Изучите IP-свойства интерфейса SVI сети VLAN 1.
*Какие выходные данные вы видите?*
>Switch#show interfaces vlan 1
>
>Vlan1 is administratively down, line protocol is down
Что интерфейс выключен, его мак адрес, сколько времени выключен, счётчик ошибок и пакетов

>
